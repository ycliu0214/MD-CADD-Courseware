# MD & CADD 課程實作範例與簡報 (MD & CADD Practical Examples & Presentations)

本儲存庫旨在整合分子動力學 (Molecular Dynamics, MD) 與電腦輔助藥物設計 (CADD) 課程相關的實作練習與教學簡報。

This repository is dedicated to consolidating practical exercises and educational presentations for Molecular Dynamics (MD) and Computer-Aided Drug Design (CADD) courses.
